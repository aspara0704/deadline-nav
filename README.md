# Deadline Navi v0.6.2

**間に合うなら、まだ下道で。**  
Deadline Naviは、高速道路へ切り替える最適なタイミングをリアルタイムに判断します。

到着希望時刻と安全マージンを守りながら、追加で支払う高速料金をできるだけ抑えるためのWebアプリです。

## v0.6.2 の主な変更

- トップコピーを正式版の「間に合うなら、まだ下道で。」へ変更
- 「通常ルート」を「Google推奨ルート」へ変更
- 「高速の時間効果」を「高速の時短効果」へ変更
- 「候補と比較の詳細」から、境界点数・探索IC数・精査件数・探索アルゴリズム説明などの開発者向け表示を削除
- 候補一覧は、IC名・到着予想・到着余裕・切替期限・ETC料金など、運転判断に必要な情報だけを表示
- v0.6.1の「ナビ変更目安」機能を継続

## 判断ロジック

1. Google Routesで下道ルートとGoogle推奨ルートを取得
2. 下道だけで実質期限内なら、高速料金0円を最適解として提示
3. 高速が必要な場合、期限付近まで下道で進める範囲を探索
4. 周辺の実在ICについて到着可能性を評価
5. 到着条件を満たす候補のETC料金をNAVITIMEで比較
6. 最安の高速入口と、高速切替期限・ナビ変更目安を提示

## 自動監視と音声

- GPSで現在地を追跡し、走行状況に応じて自動再計算
- 推奨ICや判断状態が変わったときに音声通知
- 推奨ICが決まった後は、「今はそのまま走ってよいか」「いつカーナビをそのICへ変更すべきか」も案内
- 日本語の女性音声を優先し、端末に複数の音声がある場合は設定から選択可能

## セキュリティ

- Google Maps JavaScript APIキーには公開先ドメインのHTTP referrer制限とAPI制限を設定してください。
- RapidAPIキーは不特定多数へ配布する段階ではブラウザに置かず、サーバー側プロキシへ移してください。
- APIキーをGitHubリポジトリへ直接コミットしないでください。

## 注意

本アプリは運転判断を補助する試作品です。道路規制、事故、通行止め、実際の料金・標識は通常のカーナビや道路標識でも確認してください。運転者本人が走行中に画面操作をしないでください。

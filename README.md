# Deadline Navi v0.6.1

到着期限を守りつつ、追加で支払う高速料金を最小化するWebアプリのプロトタイプです。

## v0.6 の主な変更

- 通常画面を整理し、API設定・診断・仮想時刻などの開発項目を「設定」に収納
- 候補一覧や比較詳細を折りたたみ表示に変更し、普段は「現在の判断」「推奨高速入口」「料金・到着時刻」を中心に表示
- 日本語音声は女性音声を優先して自動選択
- 端末で利用できる日本語音声を設定画面から選択可能
- 読み上げ速度・ピッチと通知文を調整し、短く自然な語り口へ変更
- v0.5.1 のGoogle API診断機能は「設定 → 開発・診断」に残す

## 中核ロジック

1. Google Routesで下道優先ルートと通常ルートを取得
2. 下道だけで実質期限内なら、追加料金0円を最適解として終了
3. 高速が必要な場合、下道ルート上の仮想地点を将来時刻込みで評価
4. 到着期限の境界周辺だけNAVITIMEの乗降IC検索で実在ICを取得
5. 実在IC群をGoogleで粗密探索し、期限直前の候補を正確評価
6. 期限内候補のETC料金をNAVITIMEで比較し、最安入口を推奨

## 音声について

ブラウザ版はWeb Speech APIを使うため、実際の声質はiPhoneに搭載・ダウンロードされている音声に依存します。v0.6はKyoko等の女性日本語音声を優先しますが、端末側で高品質音声が利用できない場合は機械的に聞こえることがあります。

iPhoneでは「設定 → アクセシビリティ → 読み上げとスピーチ（または読み上げコンテンツ）→ 声」等から日本語音声を追加・変更できる場合があります。iOSのバージョンによって項目名が異なります。

## 自動監視

2台目のiPhone等でSafariを前面表示したまま使うことを想定しています。

- 通常時：約3分または5km移動ごと
- 切替期限または下道余裕が30分以内：約1分または1.5km移動ごと
- 推奨入口または判断状態が変わったときだけ音声通知

## セキュリティ

- Google Maps JavaScript APIキーには公開先ドメインのHTTP referrer制限とAPI制限を設定してください。
- RapidAPIキーは不特定多数へ配布する段階ではブラウザに置かず、サーバー側プロキシへ移すべきです。
- APIキーをGitHubリポジトリへ直接コミットしないでください。

## 実走前チェック

- Google APIキー設定済み
- NAVITIME RapidAPIキー設定済み
- iPhoneで位置情報を許可
- 音声テスト成功
- 目的地・到着希望日時・安全マージンを確認

## 注意

本アプリは運転判断を補助する試作品です。高速入口、道路規制、事故、通行止め等は実際の道路標識および通常のカーナビでも確認してください。運転者本人が走行中に画面操作をしないでください。

## v0.6.1: ナビ変更タイミング案内

推奨ICが決まったあと、「今すぐそのICへ向かう必要があるか」を追加評価します。
現在の下道ルート上に複数の将来地点を置き、各地点まで通常走行した後でも推奨ICの高速切替期限に間に合うかをGoogle Routesで確認します。

音声は状況に応じて、たとえば次のように案内します。

- 「今はそのまま走って大丈夫です。カーナビを○○ICに変更する目安は、あと約35分です」
- 「まだ現在のルートを走れますが、ナビ変更の目安まであと約12分です」
- 「今すぐカーナビを○○ICに変更してください」

これは推奨ICそのものの高速切替期限とは別の、「現在の下道ルートをいつまで継続してよいか」の目安です。

# Deadline Navi v0.6.3

「間に合うなら、まだ下道で。」

到着時刻を守りながら、高速道路へ切り替えるタイミングと料金を判断するWebアプリです。

## v0.6.3 の主な変更

- 走行中の自動再計算を通常 **5分または5km** に抑制
- ナビ変更目安/高速切替期限が30分以内では **3分または3km**、5分以内だけ **1分または1km**
- 計算が失敗・未完了でも「計算した時刻」を記録し、10秒ごとの再試行ループに入らないよう修正
- 下道ルート周辺の候補探索が失敗した場合、**Google推奨ルート側のICも自動探索する復旧経路**を追加
- 前回の推奨ICを保持し、次回計算でも再評価。探索領域が少し変わっただけで候補が突然消えにくい構成に変更
- Google推奨ルートが期限内なのに安全なICを特定できなかった場合、期限超過ICだけを並べて「候補なし」に見せないよう修正
- NAVITIME IC検索のセッション内キャッシュを粗くし、走行中の重複APIアクセスを削減
- 音声通知の条件・頻度はv0.6.2を基本的に維持

## 自動監視

- 通常: 5分 または 5km
- 判断時刻まで30分以内: 3分 または 3km
- 判断時刻まで5分以内: 1分 または 1km

# Deadline Navi v0.6.5

「間に合うなら、まだ下道で。」

到着時刻を守りながら、高速道路へ切り替えるタイミングと料金を判断するWebアプリです。

## v0.6.5 の主な変更

- 「自動監視を開始」を **「音声案内を開始」** に変更
- 音声案内開始時に、ユーザーのタップ操作の中で `SpeechSynthesis` を明示的に起動してiPhoneの音声出力を初期化
- 自動音声が失敗した場合の `SpeechSynthesisUtterance.onerror` を監視し、従来の「無音のまま失敗する」状態を診断可能に変更
- **定期アナウンスを1〜60分、1分刻み**で設定可能（初期値10分）
- 定期アナウンスとは別に、推奨IC変更・高速利用が必要になった場合・ナビ変更時機などの重要イベントは即時案内
- GPS追跡、経路再計算、音声アナウンスの頻度を独立して管理

## iPhoneで音声が出なかった原因

旧版は、開始ボタンのタップ時には音声を再生せず、その後のGPS取得・API計算が完了した非同期コールバックから初めて `speechSynthesis.speak()` を呼んでいました。iOS Safari/PWAでは、このようにユーザー操作から時間が経った自動音声が無音になることがあります。また旧版はutteranceの非同期エラーを監視していなかったため、失敗しても画面上で原因が分かりませんでした。v0.6.5では開始ボタンのタップ中に音声を初期化し、後続の自動読み上げに備えます。

## 自動再計算

- 判断時刻まで30分以内: 3分 または 3km
- 判断時刻まで5分以内: 1分 または 1km
